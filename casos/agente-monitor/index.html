Agente de IA que monitorea el mercado para cuatro áreas

Stack

  • Python
  • Claude (Anthropic API)
  • OpenRouter
  • Google Gemini
  • feedparser
  • BeautifulSoup
  • pdfplumber
  • SMTP Microsoft 365
  • Linux
  • systemd

Contexto

En una empresa de la industria energética, cada gerente buscaba noticias a mano en más de diez fuentes: medios, sitios del sector y boletines oficiales en HTML y PDF.

Solución

Un agente en Python que corre todos los días a las 7:00. Recolecta las fuentes, filtra lo relevante, le pide a un LLM que evalúe cada noticia en función del negocio y envía un informe por mail distinto para cada área.

  • Recolección: 29 fuentes RSS y boletines oficiales (HTML y PDF de cientos de páginas).
  • Filtro determinístico: deduplicación por URL y por similitud de títulos, y reglas de palabras clave que asignan bloque y prioridad.
  • Análisis con IA: por cada noticia el modelo devuelve JSON con relevancia, implicancia para el negocio, términos a resaltar y urgencia; además genera un resumen ejecutivo de hasta tres puntos.
  • Entrega: HTML por perfil (Dirección, Comercial, Legales, Operaciones) enviado por SMTP de Microsoft 365.

Arquitectura

Decisiones de diseño

  • La IA analiza, las reglas clasifican: la prioridad base sale de reglas auditables; el LLM aporta el análisis de impacto.
  • Proveedor intercambiable: el modelo se cambia por configuración (Anthropic, OpenRouter o Gemini).
  • Robustez: cada fuente falla de forma aislada; si el LLM falla o devuelve JSON inválido, la noticia sigue con la prioridad de las reglas; reintentos ante errores transitorios.
  • Seguro por defecto: modo vista previa por omisión, verificación de entorno (--check) y prueba sin gasto de API (--test).
  • Contexto de negocio en el prompt con reglas de redacción: impacto condicional, sin recomendaciones de acción.
  • Observabilidad: log diario, costo por corrida y copia de cada informe enviado.

Resultados

  • En producción, a diario, para 4 áreas y 42 destinatarios.
  • Más de 20 noticias analizadas por día.
  • Costo de IA estimado en ~USD 1,20 por mes.
  • Boletín oficial de 607 páginas procesado en 15 s.
  • Iteración con los usuarios: el área de Legales ya pidió ajustes de cobertura.
