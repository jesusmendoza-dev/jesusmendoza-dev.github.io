Auditar una plataforma sin documentación con un MCP seguro

Stack

  • Python
  • FastMCP
  • SQL Server 2022
  • T-SQL
  • Windows Server
  • IIS
  • PowerShell
  • WinRM
  • Agentes de IA

Contexto

La empresa depende de una plataforma de gestión de un proveedor externo (.NET sobre IIS y SQL Server), sin documentación ni acceso al código. Hacía falta entenderla y auditarla sin modificar nada.

Solución

Un servidor MCP en Python (FastMCP) con 15 herramientas de solo lectura que un agente de IA usa para relevar servidores, servicios, sitios IIS, parches, firewall, permisos, grupos, configuración y la estructura completa de la base de datos.

La regla central: el modelo ve estructura, nunca valores sensibles. Las cadenas de conexión se informan solo como "presente", las variables de entorno por nombre, los archivos por metadatos y los logins sin hashes.

Arquitectura

Decisiones de diseño

  • Consultas T-SQL fijas, validadas al iniciar: solo vistas de sistema, nunca tablas de negocio.
  • Validación de entradas: nombres de base contra el catálogo real; rutas solo dentro de raíces permitidas.
  • Límites: máximo de filas, paginación, concurrencia acotada y timeouts por herramienta.
  • Secretos filtrados del lado del servidor, con tests que verifican que nunca aparezcan en la salida.
  • Confirmación humana para cualquier comando remoto fuera del MCP.

Resultados

  • 4.662 tablas, 148.213 columnas, 12.808 claves foráneas y ~22,8 millones de filas mapeadas.
  • 225 tablas sin clave primaria y 95 tablas con columnas potencialmente sensibles identificadas.
  • 24 hallazgos de seguridad documentados (servidores sin parches, firewall deshabilitado, credenciales en archivos de configuración).
  • Esquema completo relevado en ~2 minutos.
  • Suite de 848 tests sobre el servidor MCP.
