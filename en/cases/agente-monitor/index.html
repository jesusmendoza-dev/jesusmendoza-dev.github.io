An AI agent that monitors the market for four departments

Stack

  • Python
  • Claude (Anthropic API)
  • OpenRouter
  • Google Gemini
  • feedparser
  • BeautifulSoup
  • pdfplumber
  • SMTP Microsoft 365
  • Linux
  • systemd

Context

At an energy-industry company, each manager searched 10+ sources by hand: media, industry sites and official gazettes in HTML and PDF.

Solution

A Python agent running daily at 7:00: it collects 29 RSS sources and official gazettes, removes duplicates, applies auditable keyword rules, asks an LLM to assess each item's business impact as structured JSON, writes an executive summary and emails a tailored HTML report to each department.

Design decisions

Rules classify, AI analyzes; swappable LLM provider (Anthropic, OpenRouter, Gemini); per-source fault isolation and fallback when the LLM fails; preview mode by default, environment check and no-cost test mode; business context in the prompt; daily logs and per-run cost tracking.

Results

In daily production for 4 departments (42 recipients) · 20+ items analyzed per day · estimated AI cost ~USD 1.20/month · a 607-page gazette parsed in 15 s.
