Context

The company paid for a commercial RPA platform license, plus its external support, to run five Treasury, Tax, HR and Occupational Health processes. Goal: stop depending on that license and support with in-house bots producing exactly the same output.

Solution

I built five Python bots from scratch (Playwright for the ERP and tax-portal web UIs, python-docx/LibreOffice for documents, Microsoft Graph for SharePoint, REST API for the HR platform). No AI in the calculations, by design: amounts, tax and personal data need determinism.

Architecture

Design decisions

Parity before improvement; safe by default (dry run unless explicitly enabled, mandatory environment, one run per bot); per-item fault isolation, idempotent runs and masked failure alerts; least privilege with certificates and Key Vault; pinned images and deployed-commit traceability; k3s + Argo Workflows orchestration.

Results

USD 46,000 a year saved (the real license and external support cost under the contract) · 5 bots for 4 departments: 3 in production, 2 in testing · about 110-135 hours of manual work avoided per month (estimate) · 670 documents in 39 minutes with zero failures · 244/244 and 237/237 periods validated with zero differences · 2 legacy-process errors caught during treasury validation · registries of up to 1.6M records · 1,500+ automated tests.
