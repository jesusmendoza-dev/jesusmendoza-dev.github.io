Auditing an undocumented platform with a secure MCP server

Stack

  • Python
  • FastMCP
  • SQL Server 2022
  • T-SQL
  • Windows Server
  • IIS
  • PowerShell
  • WinRM
  • Agentes de IA

Context

The company depends on a third-party management platform (.NET on IIS and SQL Server) with no documentation and no source access. It had to be understood and audited without changing anything.

Solution

A Python MCP server (FastMCP) with 15 read-only tools an AI agent uses to survey servers, services, IIS sites, patches, firewall, permissions, groups, configuration and the full database structure. Core rule: the model sees structure, never sensitive values.

Design decisions

Fixed, startup-validated T-SQL over system views only; validated inputs and allow-listed paths; row limits, pagination, bounded concurrency and timeouts; server-side secret filtering with tests proving zero leakage; human confirmation for any remote command outside the MCP.

Results

4,662 tables / 148,213 columns / 12,808 foreign keys / ~22.8M rows mapped · 24 security findings documented · full schema surveyed in ~2 minutes · 848-test suite.
