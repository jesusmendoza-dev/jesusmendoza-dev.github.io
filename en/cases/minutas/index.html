AI-generated Teams meeting minutes

Stack

  • Microsoft Graph API
  • Power Automate
  • PowerShell
  • SharePoint
  • Entra ID
  • Claude (Anthropic API)

Context

Teams meeting minutes were written by hand, and decisions and tasks went undocumented. The business asked for minutes in a defined structure: executive summary, decisions, tasks, next steps and risks.

Solution

An event-driven Power Automate flow. When a transcript is ready, Microsoft Graph notifies the flow, which reads the VTT transcript and the meeting metadata, sends them to the Anthropic API (Claude Haiku) with a prompt that produces the requested structure, emails the minute to the organizer and archives it as a per-user PDF in SharePoint with an index list. A tenant-wide Graph subscription is renewed every 12 h and a watchdog runs every 6 h.

Architecture

Design decisions

Event-driven instead of 3-minute polling; idempotency by transcript id; output hardening (code-fence stripping, Outlook-safe HTML); model chosen for cost and speed; built-in platform options rejected on cost (per-user licensing: US$840-1,764/month for 84 users at list prices); PowerShell scripts that patch the live flow definitions with dry-run, JSON backup and verification; shadow mode with reconciliation before cutover; old flows stopped, not deleted, as rollback.

Results

Pilot approved, in production since July 2026 for 84 users · estimated AI cost of about USD 0.04 per meeting, against the USD 840-1,764 per month that Teams Premium or Copilot licenses would cost for the same 84 users (cost avoided, not a realized saving) · polling replaced by an event-driven model · one throttling episode resolved itself with no duplicates · documented postmortem of a platform incident.
